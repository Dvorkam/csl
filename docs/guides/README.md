# Guides

Documentation for control-station-lite, organised by who you are. Pick the guide
that matches what you're trying to do.

| If you… | Read |
| --- | --- |
| use the web UI to run scripts on machines | **[User guide](user.md)** |
| own a machine and install the agent on it | **[Target-owner guide](target-owner.md)** |
| manage the script library, users, and machines | **[Admin guide](admin.md)** |
| deploy and run the control station itself | **[Operator guide](operator.md)** |

One person often wears several hats — the operator who set up the NAS is usually
also an admin, and may own a target machine too. Read whichever guides apply.
